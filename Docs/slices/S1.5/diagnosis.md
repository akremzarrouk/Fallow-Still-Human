# S1.5 diagnosis: where the wants people act on come from

Written by hand from `diagnosis-before.md`, generated by `S15DiagnosisTests` on the S1.4 code
with nothing about motivation changed. Shipped rules, the five design conditions. Decisions
come from seeds 1 to 10 (50 mornings, 4,066 decisions, 32,555 wants raised). Behaviour comes
from the S1 batch (200 mornings).

## 1. How a want is raised

Every want is a sum. For each rule, `urgency = Σ level × factor` over its scalers, then the
urgency knee. There are no gates. A trait or a value adds the same amount at every
decision, whatever is happening. So every rule that names a trait or a value raises a
want all morning, for everybody, whether or not anything calls for it.

Seven wants, and what can raise them:

| Want | Circumstance (now) | History / evidence | Authored belief | Trait, value |
|---|---|---|---|---|
| `get_food` | hunger | | | |
| `avoid_exposure` | shame, fear | | | |
| `find_out` | memory of the missing can | | `role_claim` (Daniel 0.8, Elena 0.6) | control, fairness, dominant |
| `guard_supplies` | | belief `supplies_short` | | family_safety, cautious |
| `keep_peace` | anxiety | | | family_safety, empathetic, cautious |
| `restore_standing` | shame, anger | | | respect, proud |
| `look_after` (each person) | memory of seeing them go to pieces | ledger: comforted me, protected me | | empathetic, closeness |

Traits and values already act as dispositions elsewhere. They weight interpretation,
appraisal and every cost. Motivation is the one stage where they also generate wants on
their own.

| | Share |
|---|---|
| Urgency from traits and values | **53.0 %** |
| ... from circumstance (body, today's memories, live feelings) | 36.1 % |
| ... from history (evidence-backed beliefs, ledger) | 8.1 % |
| ... from authored beliefs | 2.8 % |
| Wants with nothing that happened behind them at all (Unsupported) | **37.4 %** |
| Wants with something behind them, but mostly disposition | 29.2 % |
| Wants mostly carried by what happened | 33.4 % |

By want: `keep_peace` is 86 % disposition and never carried mostly by circumstance.
`look_after` is 74 % unsupported, as S1.4 found. `restore_standing` is 73 % unsupported.
`find_out` is 53 % disposition plus 14 % authored belief. Only `get_food` and
`avoid_exposure` rest entirely on what is happening.

## 3. What depends on it

- **Standing still is chosen in 52.9 % of decisions,** and in **none** of them is the want
  behind it carried mostly by circumstance: 67.7 % mostly disposition, 32.3 % unsupported.
  Its appeal comes from `let_it_be` (keep the peace, 62 %) and `leave_it_alone` (guard the
  supplies, 38 %).
- **`keep_peace` is decisive in 70.0 % of decisions,** and `guard_supplies` in 43.1 %.
  `look_after` is decisive in 17.5 %.
- **Taking the trait and value part out of every want changes the top option in 42.2 % of
  decisions.** Taking out only the unsupported wants changes 25.4 %. These are static
  re-weighings at the moment of the decision, not re-run mornings.
- **Of everything chosen, the want that added most** was mostly disposition 61.9 % of the
  time, unsupported 17.1 %, and carried by circumstance only 21.0 %.
- **Only 44.2 % of urgency rests on a record that leads back to something that
  happened.** 62.6 % of wants have at least one such term.

## 4. With nothing happening

Each person as written, in a kitchen with the other three, nothing having happened to them,
not hungry. Every want raised is unsupported, and each person still does something
characteristic:

| Who | Strongest wants | Does |
|---|---|---|
| Daniel | find_out 0.90, keep_peace 0.43 | searches the room |
| Elena | keep_peace 0.83, guard_supplies 0.58 | stands still |
| Leo | keep_peace 0.77, guard_supplies 0.58 | stands still |
| Mara | look_after each person 0.31, keep_peace 0.30 | checks the pantry |

Daniel turns over a room in which nothing has gone missing, because he values control and
believes he leads. Much of what tells the four apart in the scenario is already present
here, before anything happens.

## 5. What the diagnosis supports

- The S1.4 finding is not specific to `look_after`. Every social want and both "house"
  wants carry a standing part from traits and values. It decides a large share of what
  people do, and above all whether they stand still.
- **What makes Elena and Leo alike** is that their standing wants are alike (keep the peace,
  guard the supplies) and both are served best by standing still.
- **A circumstance term rarely reaches zero once formed.** A memory presses at salience ×
  20/(20 + minutes), which falls but never ends within the morning. A gate on "is anything
  behind this want at all" would switch the whole standing part back on for the rest of the
  day after any memory of the morning. That argues against a gate, and for a form in which a
  small circumstance gets a small response.
- **Not everything standing is a disposition.** `supplies_short` is evidence-backed and
  durable, a standing want with reasons. The ledger is relationship history. `role_claim` is
  an authored belief with no evidence. They are different things, and the hypothesis is about
  traits and values only.

## 6. What the diagnosis does not show

- Whether people would still differ if traits and values only shaped responses. Section 4
  shows they differ with nothing happening. It does not show they would fail to differ when
  something does happen.
- Whether standing still would stay high for another reason. No decision here had nothing
  wanted at all, so nothing is known about what the deliberator does then. With every
  appeal zero, standing still and any other free action tie, and the seed decides.
