# Intent-carrying action: results

Generated by `IntentCarryingExperimentTests` on the primary baseline. Each arm is a whole morning run from the same content with the same seed; the only difference between arms is the intent carried onto the event that one act becomes (or, in part 3, that every search becomes). The random stream is forked per person and minute from the seed, so it cannot shift between arms.

## 1. The act, and the controls

The act is a **room search**, chosen because it is the one act the shipped data already carries an intent for: `p02` of the backstory is `search_belongings` with intent `take_responsibility`. Two real searches were found by running the baseline and taking the first search led by each want, in condition and seed order:

| Case | Who | Condition, seed | Minute | Led by | Urgency |
|---|---|---|---|---|---|
| A | daniel | daniel_ate_it, seed 1 | 4 | find_out | 0.757 |
| B | mara | mara_ate_it, seed 3 | 78 | restore_standing | 0.271 |

| Control | What was checked | Result |
|---|---|---|
| 1. Repeat | the baseline run twice, same seed | **identical**, act for act (72 acts) |
| 3. Intent removed | the hook set, returning nothing | **identical to the baseline** |
| 3b. Intent taken away again | the same hook shape, carrying null on the same act | **identical to the baseline** |
| 4. Randomness | every decision in both arms at the same minute by the same person | **held**; the stream is forked from the seed by person and minute, so an arm cannot shift it |
| 5. Physical outcome | the house at the actor's next decision: portions, everybody's room and hunger | **identical**: portions 2; daniel in kitchen hunger 0.605, elena in kitchen hunger 0.641, leo in kitchen hunger 0.498, mara in kitchen hunger 0.546 |
| 5b. The act's own event | every field but the intent | **identical**: `search_belongings`, topic `missing_can`, valence `neutral`, target `null`, minute 12 |
| 5c. The intent itself | the event's `intent` | baseline `null`, carrying arm `take_responsibility` |

## 3. Every search in fifty mornings

The five design conditions, seeds 1-10. Every search carries the meaning of the want that led it: `find_out` -> `take_responsibility`, `restore_standing` -> `assert_authority`, nothing otherwise. **This mapping is a stipulation of the experiment**, made to count how far a carried meaning reaches; it is not proposed as a rule.

| ... where the actor's beliefs changed by the end | 0 |
| ... where the actor's wants at their next decision changed | 6 |

## 4. What can read an intent at all

The six meanings a person can hold about their own act, and every rule in the shipped data that reads one.

| Self-meaning | Appraisal rules | Belief nudges | Motivation rules that read a memory of it | Authored events carrying it |
|---|---|---|---|---|
| `assert_authority` | asserting_yourself_is_done_angry | none | **none** | 1 |
| `prevent_argument` | **none** | none | **none** | 1 |
| `protect` | looking_after_someone_does_not_stop_the_worry | none | **none** | 5 |
| `share_information` | **none** | none | **none** | 1 |
| `take_responsibility` | **none** | none | **none** | 6 |
| `took_what_was_not_mine` | what_you_did_in_the_night_is_felt_as_shame, and_as_being_afraid_of_what_they_will_think | none | **none** | 3 |

A memory carrying a self-meaning is read by **no motivation rule**: every memory term in `decisions.json` names `concern`, `threat` or `reassurance`. So a preserved intent can reach a later decision only by what it stirs at the moment of the act, never by being remembered.
