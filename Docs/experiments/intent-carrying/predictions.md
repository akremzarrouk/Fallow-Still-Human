# Intent-carrying action: predictions

Written **before the experiment was run**, after the plumbing was written and before any arm
was measured. Kept as written, whatever happened.

The experiment carries an already-defensible intentional meaning onto the world event that a
search becomes, so that the searcher reads their own act by it (the path the `Interpreter`
already uses for authored history). Two meanings, both in the shipped vocabulary:
`take_responsibility` and `assert_authority`.

| # | Prediction | Why |
|---|---|---|
| P1 | In the carrying arms the actor recovers the meaning: their reading of their own search becomes the carried intent, from their own intention, at weight 1.00, in 100 % of carried acts | `Interpreter.Interpret` returns the intent for the actor when the event has one |
| P2 | The memory changes: the same search is kept as `take_responsibility` or `assert_authority` instead of `neutral` | the experience keeps the meaning |
| P3 | `take_responsibility` stirs **nothing**: no emotion, no belief, no want change, no later act change. The effect stops at memory | no appraisal rule and no belief nudge reads that meaning |
| P4 | `assert_authority` stirs **anger** (concern respect), because one appraisal rule reads it | `asserting_yourself_is_done_angry` |
| P5 | That anger raises `restore_standing` at the actor's next decision, because it reads anger toward anybody at 0.45 | the motivation rule `getting_back_what_was_taken_from_you` |
| P6 | The later **act** changes in a minority of mornings, under a fifth | Decision Sensitivity: `restore_standing` needs a median 0.29 to make another act preferred, and is outweighed at every strength in 45 % of its pairs |
| P7 | No witness changes in any arm: what other people made of the search is identical | no interpretation condition can read an intent |
| P8 | The physical outcome is identical in every arm at the moment of the act: same room, hunger, portions, searched rooms | the intent is attached after the act has changed the world |
| P9 | With the intent removed the run is identical to the baseline, act for act | the hook returns null, which is the shipped path |
| P10 | The salience of the memory rises in the `assert_authority` arm and not in the `take_responsibility` arm | salience is built from what the event stirred |

**What would falsify the hypothesis:** P1 or P2 failing (the meaning does not survive), or P4
and P5 failing while P1 holds (the meaning survives and no existing reader consumes it, for
either intent), which would be RESULT C: preserving intent alone is insufficient.
